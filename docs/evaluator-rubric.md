# Evaluator rubric

Score each category 0-2. Any 0 in correctness, verification, scope, or reliability blocks acceptance.

| Category | Question | Hard threshold | Score | Evidence |
|---|---|---|---|---|
| Correctness | Does behavior match feature entry and source requirement ids? | Yes | | |
| Verification | Did all required verification commands run and pass? | Yes | | |
| Scope discipline | Did the change stay within one feature scope? | Yes | | |
| Reliability | Do setup and checks remain rerunnable from clean checkout? | Yes | | |
| Maintainability | Are boundaries respected and docs updated? | No | | |
| Handoff readiness | Can a fresh session continue from repo files? | No | | |

## Verdict

- [ ] Accept
- [ ] Revise
- [ ] Block
