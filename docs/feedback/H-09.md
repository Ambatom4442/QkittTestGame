# H-09 — Agent tooling prerequisites

- Type: harness
- Owner: Q-HEAT
- Depends on: none

## Evidence (what we observed)

- The agent could not open PRs: `gh` is not installed and the browser session is not signed in.
- Docker Desktop is now required (H-01).

## Problem

- [ ] `AGENTS.md` quick start lists the prerequisites; `gh auth status` documented.
