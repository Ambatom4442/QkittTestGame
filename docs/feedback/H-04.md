# H-04 — Case content must be data, not code

- Type: harness
- Owner: Q-HEAT
- Depends on: none
- Status: done
- PR: #21

## Evidence (what we observed)

- Clue and deduction ids and rules (`D-03`, `D-06`, …) are hard-coded in `server/src/buildServer.js`.
- There is no `content/` folder; the validator has nothing real to validate.

## Problem

Violates NFR-61 and `architecture/05-data-model.md`; content cannot grow to the full case.

## Acceptance (done when)

- [ ] Blocking sensor `content-as-data`: fails if `E-\d\d`, `D-\d\d`, `R-\d\d` literals appear in `server/src/**` or `client/src/**` outside the content loader and tests.
- [ ] Sensor also fails if `content/cases/speckled-band/case.json` is missing.
- [ ] `content:validate` validates the real files and runs the fair-play checker on them.
- [ ] Proof: fails on current `main`.
