# P-05 — Make the test hook real

- Type: product
- Owner: dev agent
- Depends on: P-02
- Status: open

## Evidence (what we observed)

- `interact()` only records the call; `teleport()` stores the id but does not move; `fps()` always returns 60.

## Problem

Tests that use the hook prove nothing about the game.

## Acceptance (done when)

- [ ] `interact(objectId, action)` goes through the same path as a player click and returns the server's granted clues.
- [ ] `teleport(spawnId)` moves the camera to the spawn from scene content.
- [ ] `fps()` is measured; `skipAnimations()` really skips.
- [ ] Hook only available when the server has `QGAME_TEST_MODE=1`.
