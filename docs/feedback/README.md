# Feedback tickets

This folder is the in-repo home for harness (`H-xx`) and product (`P-xx`) feedback tickets.
Kit tickets (`K-xx`) stay in the kit workspace and are not copied here.

## Status states

- `open`: triaged and ready to pick up
- `in-progress`: currently being implemented on a dedicated ticket branch
- `done`: acceptance complete with linked PR evidence
- `wontfix`: intentionally not implemented (with rationale)

## Workflow

1. Run one ticket per branch and PR.
2. Link the ticket id in the PR and in commit subjects where relevant.
3. Close a ticket only after every acceptance box has evidence.
4. Keep ticket files as `H-xx.md` / `P-xx.md` for stable references.
