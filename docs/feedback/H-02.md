# H-02 — E2E tests must use a real browser; ban fake engine classes

- Type: harness
- Owner: Q-HEAT
- Depends on: H-01
- Status: done
- PR: #18

## Evidence (what we observed)

- All 8 files in `tests/e2e/` run under Vitest in Node and define fake classes (`FakeScene`, `FakePerspectiveCamera`, …).
- `@playwright/test` is not installed. No test ever opens a browser.

## Problem

E2E tests proved code against fakes, so 13 features reached `passing` while the game cannot boot.

## Acceptance (done when)

- [ ] `test:e2e` runs `@playwright/test` against the `app` service in Chromium (inside the `checks` container).
- [ ] New blocking sensor `e2e-real-browser`: fails if any `tests/e2e/**` file defines classes or objects named `Fake*`/`Mock*` for THREE, renderer, canvas or window, imports client source directly, or does not import `@playwright/test`.
- [ ] Proof: the sensor fails on current `main` and passes on a sample Playwright test.

## Notes

Unit tests may still use fakes; only `tests/e2e/` must be real.
